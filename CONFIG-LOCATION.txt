# RouterPlus - Vị trí lưu trữ Config và Data

## 📁 Thư mục chính: %LOCALAPPDATA%\9RouterPlus

### Windows Path:
```
C:\Users\<YourUsername>\AppData\Local\9RouterPlus\
```

### Cách mở nhanh:
```
Win+R → %LOCALAPPDATA%\9RouterPlus
```

═══════════════════════════════════════════════════════════════════

## 📄 Files trong thư mục

### 1. settings.json
**Chứa:**
- Dashboard URL (mặc định: http://localhost:20128)
- Chrome executable path
- Chrome User Data directory
- UI settings (theme, font scale, window size/position)
- Managed profiles mapping
- Recent profiles
- Keyboard shortcuts

**Format:**
```json
{
  "dashboardBaseUrl": "http://localhost:20128",
  "chromeExecutablePath": "C:\\Program Files\\Google\\Chrome\\Application\\chrome.exe",
  "chromeUserDataDirectory": "C:\\Users\\Username\\AppData\\Local\\Google\\Chrome\\User Data",
  "fontScale": 1.0,
  "useLightTheme": false,
  "managedProfiles": [...],
  "recentProfiles": [...],
  "windowLeft": 100,
  "windowTop": 100,
  "windowWidth": 1200,
  "windowHeight": 800,
  "enableKeyboardShortcuts": false,
  "keyboardShortcuts": {}
}
```

### 2. secrets.json
**Chứa:**
- API keys đã mã hóa bằng Windows DPAPI
- Chỉ user hiện tại trên máy này mới decrypt được

**Bảo mật:**
- ✅ Encrypted với DPAPI CurrentUser
- ✅ Không thể copy sang máy khác
- ✅ Không thể decrypt bởi user khác
- ⚠️ Không nên backup file này

═══════════════════════════════════════════════════════════════════

## 🔍 Xem config hiện tại

### PowerShell:
```powershell
# Xem settings
Get-Content "C:\Users\hieut\AppData\Local\9RouterPlus\settings.json" | ConvertFrom-Json | Format-List

# Xem secrets (encrypted - sẽ thấy gibberish)
Get-Content "C:\Users\hieut\AppData\Local\9RouterPlus\secrets.json"
```

### File Explorer:
```
1. Win+R
2. Gõ: %LOCALAPPDATA%\9RouterPlus
3. Enter
```

═══════════════════════════════════════════════════════════════════

## 🛠️ Thao tác với config

### Reset settings về mặc định
```powershell
Remove-Item "C:\Users\hieut\AppData\Local\9RouterPlus\settings.json"
# App sẽ tạo settings mới khi khởi động lần sau
```

### Xóa tất cả API keys
```powershell
Remove-Item "C:\Users\hieut\AppData\Local\9RouterPlus\secrets.json"
# App sẽ yêu cầu nhập lại keys
```

### Backup settings (không bao gồm secrets)
```powershell
Copy-Item "C:\Users\hieut\AppData\Local\9RouterPlus\settings.json" "C:\Users\hieut\Desktop\RouterPlus-settings-backup.json"
```

### Restore settings
```powershell
Copy-Item "C:\Users\hieut\Desktop\RouterPlus-settings-backup.json" "C:\Users\hieut\AppData\Local\9RouterPlus\settings.json"
```

## ⚠️ Lưu ý quan trọng

### ❌ KHÔNG nên:
- Copy secrets.json sang máy khác (sẽ không decrypt được)
- Share secrets.json với người khác (chứa API keys)
- Commit settings.json/secrets.json vào Git
- Backup secrets.json vào cloud (unsafe)

### ✅ NÊN:
- Backup settings.json (không có sensitive data)
- Ghi nhớ API keys ở nơi an toàn khác
- Reset secrets.json nếu chuyển máy
- Dùng password manager cho API keys

═══════════════════════════════════════════════════════════════════

## 🔄 Chuyển sang máy mới

### Bước 1: Backup trên máy cũ
```powershell
Copy-Item "C:\Users\hieut\AppData\Local\9RouterPlus\settings.json" "C:\Users\hieut\Desktop\"
```

### Bước 2: Trên máy mới
1. Cài RouterPlus
2. Copy settings.json vào %LOCALAPPDATA%\9RouterPlus\
3. Mở RouterPlus
4. Nhập lại API keys cho OpenRouter/Ollama

### Bước 3: OAuth providers (Codex/Kiro/Kimchi)
- Nhấn "Thêm" và làm lại OAuth flow
- Tokens mới sẽ được lưu tự động

## 🐛 Troubleshooting

### App không khởi động / crash
```powershell
# Rename settings để force reset
Rename-Item "C:\Users\hieut\AppData\Local\9RouterPlus\settings.json" "settings.json.old"
```

### API keys không work
```powershell
# Xóa và nhập lại
Remove-Item "C:\Users\hieut\AppData\Local\9RouterPlus\secrets.json"
```

### Quên Chrome path đã config
```powershell
# Xem trong settings
(Get-Content "C:\Users\hieut\AppData\Local\9RouterPlus\settings.json" | ConvertFrom-Json).chromeExecutablePath
```

## 📊 Kích thước files

Typical sizes:
- settings.json: 1-5 KB
- secrets.json: 0.5-2 KB

Nếu file lớn hơn nhiều → có thể corrupt, nên backup và reset.

## 💡 Tips

### Xem settings đẹp hơn:
```powershell
Get-Content "C:\Users\hieut\AppData\Local\9RouterPlus\settings.json" | ConvertFrom-Json | ConvertTo-Json -Depth 10
```

### Check folder tồn tại:
```powershell
Test-Path "C:\Users\hieut\AppData\Local\9RouterPlus"
```

### Tạo thư mục thủ công (nếu cần):
```powershell
New-Item -Path "C:\Users\hieut\AppData\Local\9RouterPlus" -ItemType Directory -Force
```
