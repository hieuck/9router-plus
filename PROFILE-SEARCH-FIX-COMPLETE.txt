# Fix Bug Search Profile - Hoàn Thành

## Vấn Đề
Chức năng tìm kiếm profile không hiển thị trên giao diện mặc dù backend đã được implement đầy đủ.

## Nguyên Nhân
File MainWindow.xaml thiếu TextBox để người dùng nhập từ khóa tìm kiếm. Grid layout trong sidebar nhảy từ Grid.Row="4" (provider filters) thẳng đến Grid.Row="6" (danh sách profile), bỏ qua Grid.Row="5".

## Giải Pháp
Đã thêm search box tại Grid.Row="5" trong MainWindow.xaml với:
- TextBox binding đến ProfileSearchText với UpdateSourceTrigger=PropertyChanged để filter realtime
- Placeholder "Tìm profile..." hiển thị khi TextBox rỗng
- Button xóa (✕) binding đến ClearProfileSearchCommand
- Style nhất quán với SidebarSearchStyle

## Thay Đổi
File: src/RouterPlus.App/MainWindow.xaml
- Thêm Grid.Row="5" Border chứa search TextBox và nút clear
- Đặt giữa phần provider filter và danh sách profile
- Dùng TextBlock overlay cho placeholder thay vì PlaceholderBehavior (không tồn tại)

## Cách Hoạt Động
1. Ô search hiển thị phía trên danh sách profile
2. Gõ để filter profile theo tên hoặc tên thư mục (không phân biệt hoa thường)
3. Filter realtime khi gõ
4. Click ✕ để xóa từ khóa tìm kiếm
5. Số lượng profile đã filter tự động cập nhật

## Backend Đã Sẵn Sàng
- ProfileSearchText property với logic filter
- ApplyProfileFilter() method cập nhật FilteredProfileRows
- ClearProfileSearchCommand để clear search
- ChromeProfileFilter.Filter() tìm kiếm trong tên và directory name
