🔧 TECHNICAL DETAILS

Constructor:
  public RouterApiClient(HttpClient httpClient, string dashboardBaseUrl)
  {
      _usageReader = new UsageDatabaseReader();  // %APPDATA%\9router\db\data.sqlite
  }

ListAllConnectionsAsync:
  var usageByConnection = _usageReader.GetTodayUsageByConnection();
  return connections.EnumerateArray()
      .Select(element => ParseConnection(element, usageByConnection))

ParseConnection logic:
  1. Try API fields (usageCount, limitCount, usageResetAt)
  2. Try expiresAt for OAuth providers
  3. Try database: usageByConnection.TryGetValue(id, out var dbUsage)
     → usageCount = dbUsage.Requests
  4. Try inference from errors
  5. Return ProviderConnection with best available data

⚠️ KNOWN LIMITATIONS

1. Database only tracks requests, not limits
   → Hiển thị "129 requests" thay vì "129/10000"
   → limitCount váẫn null (không có progress bar %)

2. usageResetAt = end of today
   → Database reset mỗi ngày, không có info về monthly/weekly limits

3. Database might be locked
   → UsageDatabaseReader handle gracefully, return empty dict

4. Database only has today's data
   → Không có historical data
