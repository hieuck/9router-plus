===============================================================================
ROOT CAUSE IDENTIFIED
===============================================================================

Commit 9dab61b added GetTokenExpirationByConnection() method but:
❌ ParseConnection() DID NOT actually call it
❌ Still parsed expiresAt from API response FIRST  
❌ Database read was NO-OP (never used)

Code flow was:
1. Parse expiresAt from API element ❌
2. Read tokenExpirationByConnection from database (ignored!) ❌
3. Use API expiresAt → wrong data ❌

===============================================================================
FINAL FIX (Commit c30f13c)
===============================================================================

BEFORE (BROKEN):
  var expiresAt = element.TryGetProperty("expiresAt", ...) // Always from API
  
AFTER (FIXED):
  DateTimeOffset? expiresAt = null;
  
  // 1. Try database FIRST
  if (tokenExpirationByConnection.TryGetValue(id, out var dbToken))
  {
      expiresAt = dbToken.ExpiresAt;  // PRIMARY source
  }
  
  // 2. Fallback to API only if database has no data
  if (!expiresAt.HasValue)
  {
      expiresAt = element.TryGetProperty("expiresAt", ...) // FALLBACK
  }
