   d. Inference chỉ override usageResetAt nếu chưa có

🎯 LOGIC FLOW

Step 1: Parse all fields from API
  - usageCount, limitCount, usageResetAt (may be null)
  - expiresAt, expiresIn, lastRefreshAt (may be null)

Step 2: Use expiresAt for OAuth providers
  if (expiresAt.HasValue && !usageResetAt.HasValue)
    usageResetAt = expiresAt

Step 3: Fallback to inference if needed
  if (!usageCount && !limitCount)
    infer from error messages

Step 4: Create ProviderConnection with all data
  return new ProviderConnection(...)

- Usage quota = Số lượng requests đã dùng / limit
